Voice Transcribing

How recordings and audio files are transcribed by Gemini 3.5 Transcribe.

These three options apply to Voice Transcribing only — live Voice Typing is handled by the browser and has no equivalents.

  • Language — a hint that improves accuracy. Automatic lets the model detect the language itself and follow you when you switch languages mid-recording.
  • Mode — Verbatim writes exactly what was said, keeping filler words and false starts. Smart removes the filler words and cleans up the formatting for readability.
  • Custom vocabulary — terms, product names and technical jargon the model should recognise. Use it for words that are otherwise misheard.

Automatic detects more than 85 languages and handles switching between them.

Verbatim is the default: nothing is removed from what you said.

Separate terms with commas. Each term is a phrase, proper noun or technical word the model should transcribe correctly.

Saved recordings

Checking for unsent recordings…

    Recovered transcript

    Every recording is saved on this computer before it is sent, and deleted as soon as the transcript comes back. Anything still here failed to transcribe — you can send it again instead of recording it a second time. These files never leave this browser unless you retry them.

    Recordings are sent straight from this extension to Google's Gemini API, using your own key. Nothing is routed through a server operated by the extension's author. The key is kept in this browser's extension storage, is never sent anywhere except to Google as a request header, and is never shown again after you save it.

    Create a key in Google AI Studio. Google charges your own account for transcription, so a key with billing enabled will bill you. Restrict the key to the Gemini API so it cannot be used for anything else.

    Voice Typing does not need a key and does not use this mode. This mode needs your browser to be able to reach generativelanguage.googleapis.com, which some networks and countries block; where it is blocked, no key will make it work.

    The default is Gemini 3.5 Transcribe, the model these options are documented for. Change this if your Google AI account exposes a different transcription model alias.

    Custom voice commands

    Map any spoken phrase to the text you want inserted.

    When the transcript contains a phrase, its replacement is inserted instead of the spoken words.

    • Say this — the phrase that triggers the command. Multi-word phrases match exactly, case-insensitively.
    • Type this — what gets inserted. Use \n for a line break and \t for a tab.
    • Short punctuation replacements hug the previous word automatically.
    • Leave Type this empty to insert nothing (mutes the phrase).
    • Custom commands work in every language and override the built-in ones.
    • Examples: eye packet → iPacket, ایمیل من → you@example.com, امضا → \n—\nعلی.
